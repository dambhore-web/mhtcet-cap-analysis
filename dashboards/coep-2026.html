Cells based on fewer than 3 students are faded. Treat them as single data points, not cutoffs.

All India merit list

JEE percentile check against COEP closing ranks

The CET Cell's final All India merit list ranks 240,114 candidates. The first 98,360 are ranked by JEE (Main) percentile; candidates without JEE come after them. Each COEP All India seat holder appears in that list, so the closing seat can be read as an All India merit number.

All India seats are not reserved by category, so category and gender don't change this result.

"Top %" is the closing merit number as a share of the 98,360 JEE-ranked candidates on the All India list.

Method

How these numbers were made

  • Source: CAPR-I to CAPR-IV allotment PDFs for institute 16006 on fe2026.mahacet.org, parsed row by row. 5,467 of 5,468 rows parsed with a seat type; one Round I row had none and was left out.
  • Closing merit is the highest state general merit number holding a seat of that type in that round. State-level seats only; All India seats are shown separately by JEE percentile.
  • Seat type codes follow the CET Cell legend: first letter G = general, L = ladies; final S = state level. DEF/PWD = defence and persons-with-disability quotas, TFWS = tuition fee waiver, ORPHAN = orphan quota.
  • Turnover counts a candidate as having left a branch if they are not in that branch's list in the next round. That includes moving to another COEP branch.
  • All India merit numbers come from FE2026_PCMAI_MeritList_Final.pdf (published 27/07/2026). 240,114 of 240,141 rows were parsed; all 948 COEP All India rows matched it on both merit number and percentile. The percentile checker interpolates between sampled points of that list, so its rank is an estimate within a few places.
  • Candidate names and application IDs were not used.
