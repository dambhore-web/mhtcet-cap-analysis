CompassDesign pass, October 2026

Mockups

Static pages with real CAP 2026 data from the local API. Each one has a Desktop/Phone switch and design notes you can hide.

Merit ruler

One log-scale strip of closing ranks with a pin for “you”. The same idea on every page: all of CAP, one student's options, one college, one branch's years.

Type

Anek Latin for headings and big numbers (Ek Type, Mumbai). Poppins for text. Geist Mono for small figures.

Colour

The app's Calm blue palette, unchanged. Blue means within reach; amber is the latest round.
