Where our numbers come from

Every cutoff in Compass is read by software from the PDFs the State CET Cell publishes, checked, and stored with the file and page it came from.

  1. 01Official PDFs

    Cutoff lists for every round, merit lists, the seat matrix and allotment lists, from the State CET Cell.

  2. 02Read by code

    Parsers pull out college, branch, seat type, round and closing merit. Nobody types numbers in by hand.

  3. 03Checked

    Seat counts must match each branch's printed “CAP Seats”, and Round I cutoffs must match the allotment lists.

  4. 04Stored with source

    Each value keeps its PDF name and page, so any number can be traced back. No candidate names or application IDs are kept.

This is a real pipeline, in order, so the steps are numbered. Everything below is the live /api/meta answer.
